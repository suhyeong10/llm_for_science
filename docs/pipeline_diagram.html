Docling + Formula Enrichment (참고)

Docling은 IBM이 오픈소스로 공개한 PDF 파서로, 기본 모드에서는 텍스트+테이블을 추출합니다 (3.1초/페이지).
Formula enrichment 옵션을 켜면 PDF 속 수식 영역을 감지하여 LaTeX 코드로 변환합니다.

실제 테스트 (42페이지 논문): 327개 수식을 LaTeX로 추출 성공. 하지만 14초/페이지로 속도가 급감하여,
48,652건 전체에 적용 시 ~56일 소요 (CPU 기준) → 현실적이지 않아 기각.

선택 근거: LaTeX 논문 167,895건이 이미 수식을 포함하고 있으므로, PDF 48,652건은 pymupdf4llm으로 빠르게 파싱하고,
수식이 중요한 경우 향후 GPU 서버에서 MinerU로 교체하는 전략을 채택.
